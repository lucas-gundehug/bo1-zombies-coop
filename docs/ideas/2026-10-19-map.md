# Idea: an in-game map (next project after the cheat menu)

Lucas's words: "I get lost in the game about where my friends are, what room I'm in, what doors I have not unlocked
yet and would like a map for that." No teleport wanted.

Wanted:
- Where the friends are (coloured dots, the co-op card's player colours).
- Which room ("zone") each player is in, with proper names per map (the game's are technical, e.g. foyer_zone).
- Which doors and debris are still closed, with their price.

Shape (Lucas, 2026-10-19): first a big pop-up map on a key; later maybe a small version in a corner that moves with
the player.

Findings so far (not built, not verified): the game has no overview picture. Plan: the game script publishes player
positions, each player's zone (zone volumes, level.zones), the closed zombie_door / zombie_debris triggers with cost and
position, and the path nodes per zone; the card draws rooms as shapes from the nodes, labelled, players and locks on
top. Multi-floor maps (Five, Kino) need a per-floor view. Needs a brainstorm with Lucas before building.
